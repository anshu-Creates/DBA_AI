# Fundamentals of Data Processing

## Data

* It is a collection of raw fact and figures which is not meaningful on its own.

## Information

* It is the organised form of data.

## Data Processing

* `What :` Performing certain operations on data.
* `Why :` To make the data clean & sorted.
* `Where :` ETL Tools like Excel, PowerBI, SQL, R Programming, Python, Tableu
* `How :` Data Collection -> Data Cleaning & Processing -> Data Modelling -> Data Visualizations

## Data Management Branches

## Data Types

1. Structured Data : Can be edited, e.g. Excel Table
2. Semi-Stuctured Data : e.g. XML, JSON
3. Unstructured Data : Can't be edited, e.g. Images, Videos, etc.

## Why is data processing important ??

1. Saves Time
2. Data Accuracy
3. Decision Making
4. Easy Access
5. Minimal Storage Options
6. Risk Analysis
7. Generate Reports/ Documentation

 ## Types of Data Processing

 2. Descriptive Analysis : why this Problem occured is provided in a description.
 3. Predictive Analysis : The future trends / figures can be made.
